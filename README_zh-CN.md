# InkWeaver——漫画叙事与自动化技术交汇之地，专为数字收藏家打造的精选工具。

在这里，漫画的叙事脉络与自动化技术相融合——专为数字收藏家打造的精心整理工具。

**InkWeaver**并非普通的漫画下载工具。它是一款精心设计的自动化归档助手，专为那些重视条理性、一致性，以及享受精心整理的数字藏书所带来的愉悦感的读者打造。源自MeManga的最初灵感，InkWeaver重新定义了这一流程：它不只是简单地获取章节内容，而是将它们编织成结构清晰、可搜索且视觉上和谐统一的收藏集，既尊重原作本身，也契合收藏者的审美需求。

无论你是喜欢编写脚本在周末一口气追完所有内容的资深用户，还是偏爱简洁友好界面的桌面应用爱好者，InkWeaver 都能满足你的需求。它精通元数据、封面图及章节排序等规则，可将原始下载的文件转化为精致的个人档案。

## 桌面应用：便捷的数字书架 📚

这款桌面应用采用 **PyQt6** 和 **QtQuick** 开发，因而拥有流畅的动画界面。您可以：

- 通过封面缩略图的**砌砖式网格**浏览您的藏书库。  
- 按标题、作者或类型标签进行**搜索**。  
- 按语言、完成状态或添加日期进行**筛选**。  
- 在阅读已收集的书籍时将下载任务**排队**。  
- 在开始完整下载之前先**预览**章节内容。

该应用会记住您的上次阅读位置、首选语言以及阅读设备的相关设置。它旨在成为您个人漫画收藏的**入口**——不仅是一个下载工具，更是一位阅读伴侣。

## 命令行工具：指挥家的指挥棒 🎼

## 命令行界面：指挥家的指挥棒 🎼

对于那些偏爱终端冷峻精准体验的用户，InkWeaver 提供功能丰富的命令行界面，其中包含可组合的各类命令：

```bash
inkweaver fetch --series "One Piece" --chapters 1-50 --output./my_manga
inkweaver metadata --update --series "Berserk" --language jp
inkweaver schedule --daily --time 03:00 --output /mnt/nas/manga
inkweaver watch --series "Vinland Saga" --monitor --interval 900
```

该 CLI 支持以下功能：
- **JSON 输出**，便于接入其他工具（如 `jq`、`fzf`、`notify-send`）。
- **试运行模式**，可预览即将下载的内容。
- **环境变量集成**，可用于设置 API 密钥和自定义路径。
- **日志级别**，从 `silent` 到 `trace` 不等。

它专为那些希望将漫画收藏整合到更广泛的媒体自动化流程中的高级用户而设计。

# 为何取名“InkWeaver”？名称背后的理念 🕸️

## 为何取名“InkWeaver”？名称背后的理念 🕸️

这一名称源自织布工在织布机前工作的比喻。每一根线（即每一章）都被精心挑选、拉紧并排列，从而构成一个完整的整体。这里没有匆忙，只有慎重的筛选。InkWeaver通过确保每张图片均为高分辨率、每页顺序正确且每个文件的命名一致，来尊重原作者的艺术匠心。

我们坚信，**收集应当是一种保护行为**，而非囤积。正因如此，InkWeaver 内置了**收藏健康检查工具**，能够检测出损坏的图片、缺失的页面或错误的元数据。

## 元数据：档案的灵魂 📖

## 元数据：档案的灵魂 📖

InkWeaver 会为每次下载的内容附带一份结构化的元数据文件。以下是一个 `metadata.json` 的示例：

```json
{
  "系列": "幽游白书！",
  "来源平台": "mangaplus",
  "语言": "英文",
  "章节": 42,
  "总页数": 28,
  "分辨率": "1920x1080",
  "提取时间": "2026-04-14T23:15:00Z",
  "校验和": "sha256:abc123..."
}
```

这些元数据可以被 Komga、Kavita 或 Calibre 等第三方工具读取。对于高级用户而言，使用 `inkweaver metadata --export csv` 命令即可输出完整的图书馆清单。

## 导出配置文件：定制您的图书馆 🧵

## 导出配置：定制您的藏书库 🧵

InkWeaver 支持多种输出配置文件：

- **适合阅读器（CBZ格式）**——专为平板电脑设计，首页即为封面。
- **归档格式（图片格式）**——按卷分类存放每章的原始JPEG/PNG图片。
- **便携格式（PDF格式）**——将每章的所有页面合并为单个PDF文件。
- **极简格式**——仅包含图片文件，无文件夹也无元数据。

您可以在 `~/.inkweaver/profiles.yaml` 中定义自定义的输出配置文件。

## 定时下载：准备就绪时唤醒我 ⏰

设定定时任务后，让 InkWeaver 在后台运行。它会根据系统的电量状态来决定操作——**当电池电量低于 20% 时会跳过下载**。该功能专为笔记本电脑、服务器及 NAS 设备设计。

示例日程：每天凌晨3点，下载“活跃”列表中系列作品的新增章节。

## 24/7 支持？不——24/7 的可靠性 🛡️

## 7×24小时客服？不必——全天候的稳定性 🛡️

虽然凌晨3点没有人工客服热线，但InkWeaver采用了**自我修复架构**。如果下载过程中出现故障，它会以指数级退避策略最多重试3次。若来源网址结构发生变化，InkWeaver会记录详细的错误信息并推荐替代来源。该系统**绝不会悄悄跳过任何一章内容**。

如需人工支持，我们提供了 `docs/` 文件夹及社区维基。您可以通过 GitHub Issues 报告漏洞，系统会自动附上相关日志。

## 自适应界面：随您的屏幕尺寸灵活调整 📱💻🖥️

桌面客户端采用**流式布局**。在屏幕较小的设备上，它会切换为单列列表形式；而在大屏幕设备上，则会以网格布局展示并附带预览工具提示。默认主题为**深色主题**——因为阅读漫画在夜间最为舒适——同时也提供了适合日间使用的浅色主题选项。

字体大小会自动适配系统的缩放比例。该用户界面已针对125%、150%及200%的缩放比例进行过测试。

## 流式传输集成（实验性功能）🌊

InkWeaver 还可通过内置的 HTTP 服务器，选择性地将章节**直接流式传输**到本地浏览器或电子阅读器中。这不是下载操作，而是实时预览，有助于帮助你决定是否要收藏某部作品。

```bash
inkweaver serve --port 8080 --library./manga
```

然后在您网络中的任意设备上打开 `http://localhost:8080` 即可。
