# InkWeaver

マンガの物語の糸が自動化という織機と出会う場所――整理整頓を大切にし、体系的で探しやすく、視覚的にも統一感のあるコレクションを楽しみたいデジタルコレクターのためのキュレーターです。

**InkWeaver**は単なるマンガダウンローダーにとどまりません。整理性や一貫性、そして丁寧に構築されたコレクションがもたらす静かな喜びを重視する読者のために設計された、思慮深い自動化アーカイブツールです。MeMangaという元のアイデアから生まれたInkWeaverは、単に各話を取得するだけでなく、それらを構造化され、検索可能で、視覚的にも一貫性のあるコレクションへと織り上げ、原作の価値とコレクターの感性を大切にします。

週末の読書会のためにスクリプトを自作する上級ユーザーであれ、シンプルで使いやすいUIを好むデスクトップアプリ愛好家であれ、InkWeaverはどちらのニーズにも応えるように設計されています。メタデータ、表紙画像、章の順序といった要素を活用し、単なるダウンロードしたファイルを洗練されたパーソナルアーカイブへと変えてくれます。

---

## 概要 🌐

InkWeaverは二つのインターフェースを備えたシステムです。アマチュアコレクター向けの**反応性の高いデスクトップアプリケーション**と、高度な自動化を求めるユーザー向けの**コマンドラインインターフェース**がそれにあたります。その核心的な理念は「混沌から秩序を生み出す」ことです。各章にはタグが付けられ、各巻は体系的に整理され、すべての表紙もそのまま保存されます。このツールは静かで迅速、かつ細心の注意を払って動作し、不要なものや重複、壊れたリンクは一切存在しません。

これをデジタルの織機だと考えてみてください。あなたが糸（漫画シリーズや章の範囲）を用意すれば、InkWeaverがそれらを整理されたフォルダ、メタデータ、画像セットという美しい織物に仕上げてくれ、どんな電子書籍リーダーやタブレットでも読むことができる状態にしてくれます。

## 主な機能 🧶

| 機能 | 説明 |
|---------|-------------|
| **二重モードアーキテクチャ** | ウィジェット風のデスクトップGUIを使ってワンクリックでコレクションを作成したり、CLIを使って一括で無人ダウンロードを行ったりできます。 |
| **賢い章の重複排除** | 新しいバージョンが存在しない限り、既にダウンロードされた章は自動的にスキップされます。 |
| **メタデータの埋め込み** | 各巻／フォルダには、シリーズ名、章番号、発売日、出典情報が記載された`.json`形式のメタデータファイルが同梱されます。 |
| **表紙画像の抽出** | 各巻の表紙画像を自動的にダウンロードし、`cover.jpg`として保存します。 |
| **対応型UI** | 13インチのノートパソコンから27インチのモニターまで、さまざまな画面サイズに対応し、快適な閲覧を実現します。 |
| **多言語対応のメタデータ** | 日本語、英語、スペイン語、フランス語でのメタデータに対応。UIの言語は自動で検出されます。 |
| **24時間365日動作するバックグラウンドサービス** | InkWeaverを常に起動したままにしておけば、設定可能なオフピーク時間帯にダウンロードをスケジュールできます。 |
| **プロファイルのエクスポート** | CBZ、単純な画像、PDFなど、出力形式を自由にカスタマイズできます。 |
| **再試行・再開機能** | 接続が切れても、InkWeaverは最後に正常に処理された部分から再開するため、無駄な帯域幅の消費はありません。 |

## デスクトップアプリ：歩き回るデジタル本棚 📚

デスクトップアプリケーションは**PyQt6**および**QtQuick**を使用して開発されており、流れるようなアニメーション付きのインターフェースを提供します。以下の操作が可能です：

- カバーのサムネイルで構成される**マザーボードグリッド**を通してライブラリを閲覧できます。  
- タイトル、著者、ジャンルタグで**検索**が可能です。  
- 言語、完成状況、追加日付で**フィルタリング**できます。  
- 既に収集した書籍を読んでいる間にダウンロードを**キューイング**できます。  
- 完全なダウンロードを実行する前に章を**プレビュー**できます。

このアプリは、最後に閲覧していた位置やお好みの言語、読書用デバイスの設定情報を記憶します。単なるダウンロードツールではなく、個人のコレクションへの**入口**となるよう設計されており、読書のパートナーとしても機能します。

## CLI：指揮者のバトン 🎼

ターミナルの厳密で正確な操作性を好む方々のために、InkWeaverは組み合わせ可能なコマンドを備えた充実したCLIを提供しています：

```bash
inkweaver fetch --series "One Piece" --chapters 1-50 --output./my_manga
inkweaver metadata --update --series "Berserk" --language jp
inkweaver schedule --daily --time 03:00 --output /mnt/nas/manga
inkweaver watch --series "Vinland Saga" --monitor --interval 900
```

このCLIは以下の機能をサポートしています：
- 他のツール（`jq`、`fzf`、`notify-send`）に渡すための**JSON出力**。
- ダウンロードされる内容を事前に確認できる**ドライランモード**。
- APIキーやカスタムパスを管理するための**環境変数連携**。
- `silent`から`trace`までの**ログレベル設定**。

これは、マンガコレクションをより幅広いメディア自動化パイプラインに統合したい上級ユーザーのために設計されています。

## なぜ「InkWeaver」なのか？その名前に込められた思想 🕸️

この名前は、織機で織物を織る人になぞらえて名付けられました。各糸（章）が丁寧に選ばれ、適切な張力で配置されることで、一つの調和のとれた全体が形成されます。急ぐことなく、慎重かつ意図的にコレクションが構築されていきます。InkWeaverは、すべての画像が高解像度であり、すべてのページが正しい順序にあり、すべてのファイルが一貫した名前で管理されるようにすることで、オリジナルクリエイターの技術を尊重しています。

私たちは、コレクションを築くことは貯蔵ではなく、**保存という行為**であるべきだと考えています。そのため、InkWeaverには破損した画像や欠落しているページ、不正なメタデータがないかをスキャンする**コレクション健全性チェッカー**が搭載されています。

## メタデータ：アーカイブの魂 📖

InkWeaverは、ダウンロードされる各ファイルに構造化されたメタデータファイルを添付することで、その価値を高めています。以下が`metadata.json`の例です：

```json
{
  "series": "ヨツバ＆！",
  "source": "mangaplus",
  "language": "en",
  "chapter": 42,
  "total_pages": 28,
  "resolution": "1920x1080",
  "extracted_at": "2026-04-14T23:15:00Z",
  "checksum": "sha256:abc123..."
}
```

このメタデータは、Komga、Kavita、Calibreといったサードパーティツールでも読み取ることができます。上級ユーザー向けには、`inkweaver metadata --export csv` コマンドを使うことで、ライブラリの全項目を含む一覧を出力できます。

---

## エクスポートプロファイル：ライブラリを自分好みにカスタマイズ 🧵

InkWeaverでは、複数の出力プロファイルに対応しています：

- **Reader-Ready (CBZ)** – タブレットに最適。表紙を最初のページとして含みます。  
- **Archive (Images)** – 各章を個別のJPEG/PNGファイルで保存し、巻ごとに整理します。  
- **Portable (PDF)** – 各章のすべてのページを1つのPDFファイルにまとめます。  
- **Minimal** – 画像ファイルのみで、フォルダやメタデータは含まれません。

`~/.inkweaver/profiles.yaml` にて、カスタムの出力プロファイルを定義できます。

## スケジュールによるダウンロード：準備ができたら起動して ⏰

スケジュールを設定してInkWeaverをバックグラウンドで実行させましょう。システムの電源状態を考慮し、**バッテリー残量が20％未満の場合はダウンロードをスキップ**します。これはノートパソコン、サーバー、NASデバイス向けに設計されています。

例として、毎日午前3時に「アクティブ」リスト内のシリーズの新しい章をすべてダウンロードするようスケジュール設定できます。

---

## 24時間365日のサポート？いいえ——24時間365日の信頼性こそが重要です 🛡️

午前3時には人間によるサポートチームが対応していませんが、InkWeaverは**自己修復型のアーキテクチャ**を基盤としています。ダウンロードが途中で失敗した場合、指数関数的に間隔を広げながら最大3回まで再試行します。また、ソースのURL構造が変更された場合でも、InkWeaverは詳細なエラーを記録し、代替のソースを提案します。このシステムは**決して何もせずに章を省略することはありません**。

人間によるサポートについては、`docs/` ディレクトリとコミュニティ Wiki を用意しています。バグの報告は、自動的にログが添付される GitHub Issues を通じて行うことができます。

---

## レスポンシブUI：お使いの画面に合わせて自動調整 📱💻🖥️

デスクトップクライアントは**フルイドレイアウト**を採用しています。小さな画面では単一列のリストに切り替わり、大きな画面ではプレビュートールチップ付きのグリッド表示になります。デフォルトは**ダークテーマ**で、これは夜間に漫画を楽しむのに最適だからです。日中向けにはライトテーマも用意されています。

フォントサイズはシステムのスケーリングファクターに合わせて調整されます。UIは125％、150％、200％のスケーリングでテストが行われています。

## ストリーミング連携機能（実験版）🌊

InkWeaverでは、内蔵のHTTPサーバーを利用して、チャプターをローカルのブラウザや電子書籍リーダーに直接**ストリーミング配信**することも可能です。これはダウンロードではなく、リアルタイムでのプレビュー機能です。シリーズを購入するかどうかを判断するのに役立ちます。

```bash
inkweaver serve --port 8080 --library./manga
```

その後、ネットワーク上のどのデバイスからでも `http://localhost:8080` を開いてください。
